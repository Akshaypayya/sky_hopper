An exhilarating, fast-paced vertical arcade mobile game built with Flutter by **Black Wolf Motion**. Take to the skies, dodge hostile drone obstacles, gather airborne coins, unlock achievements, and chase legendary high scores in a vibrant, audio-packed casual gaming experience.

---

## 🎮 Key Features

- **🚀 Dynamic Airborne Gameplay**: Fluid hopping, flying, and falling mechanics powered by responsive sprite animations (`player_jump.png`, `player_fly.png`, `player_fall.png`).
- **🛸 Hazardous Drone Obstacles**: Test your reflexes dodging hostile aerial patrol drones (`sprites/drone.png`).
- **🪙 Coin Collection & Combos**: Snatch airborne gold coins during flight to multiply your score and boost run totals (`sprites/coin.png`).
- **🏆 High Scores & Achievements**: Challenge your personal bests with celebratory high-score fanfares and unlocked achievements (`highscore.wav`, `achievement.wav`).
- **🎵 Immersive Retro Audio**: High-energy background soundtrack (`bgm.mp3`) paired with dynamic sound effects for jumps, coin grabs, impacts, and game-over events.
- **📱 AdMob Integration**: Built-in support for Google Mobile Ads for seamless monetization.

## 📲 Installation

To install the release build on an Android device:

1. Download the [`app-release.apk`](app-release.apk) file from this repository or the Releases section.
2. Enable **Install from Unknown Sources** in your Android device settings if prompted.
3. Open the APK file on your device and tap **Install**.
4. Launch **Sky Hopper** and jump right into the action!

Alternatively, install via ADB:
```bash
adb install -r app-release.apk
```
